# ML-Powered Personal Finance Advisor

## Overview
This project provides a **smart financial advisor** using **machine learning** to analyze income, expenses, and financial goals. It offers insights into **budgeting, savings recommendations, and investment strategies** based on historical trends.

## Features
✅ **Income & Expense Tracking** – Categorizes transactions for better financial insights  
✅ **Budget Recommendations** – Suggests spending limits based on past behavior  
✅ **Savings Insights** – Estimates future savings based on user patterns  
✅ **Investment Guidance** – Recommends investment options based on financial goals  
✅ **Data Visualization** – Generates interactive charts for financial analysis  

## Requirements
Install the required dependencies using:
```bash
pip install pandas numpy scikit-learn matplotlib seaborn flask
```

## Usage
1. **Run the script:**
```bash
python finance_advisor.py
```
2. **run streamlit dashboard**
streamlit run finance_advisor.py

- Monthly Budget Breakdown 📊
