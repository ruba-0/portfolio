# 📌 Sales Forecasting with ARIMA & ML

## 🔹 Project Overview  
This project predicts daily sales using ARIMA and a machine learning model. It includes a dynamic dashboard for visualization using **Streamlit**.


## Steps and Instructions

--> Place Walmart_Sales.csv file in the same folder as the script.

--> Run below command on terminal:

	streamlit run demand_forecasting.py
